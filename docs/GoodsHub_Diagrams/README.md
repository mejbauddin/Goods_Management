# GoodsHub diagrams

Seven diagrams for Group 2, Goods Management, Software Design and Architecture.

- png/: images for Word and PowerPoint.
- svg/: scalable images for zooming and printing.
- sources/: editable PlantUML (.puml); original Mermaid (.mmd) for architecture and ER.
- index.html: open in your browser after extracting the ZIP to view all diagrams.

The architecture and ER images use equivalent PlantUML versions of the Mermaid sources. The class diagram represents domain concepts, not implemented Python classes. Audit references are historical references, not foreign keys.

The activity and sequence diagrams are detailed and tall: use a full page or split across slides for readable presentation text.

To edit and regenerate, use PlantUML with a .puml source.
