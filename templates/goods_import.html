Header contract

exact order not required 
code,name,category,unit,weight,description
  • code — unique, 2–30 characters, stored upper-case.
  • category — must match an existing category name.
  • unit — must be one of the allowed units.
  • weight — number greater than 0.
  • Rows with an existing code are skipped, not overwritten.

How the batch runs

per row
  1. 01
    Decode

    Read as UTF-8-sig, then check the header against the contract.

  2. 02
    Validate

    Normalise the code, resolve the category, parse the weight and unit.

  3. 03
    Write

    Insert the goods row and its audit entry inside one transaction.

  4. 04
    Report

    Collect imported / skipped / failed counts with the reason per line.

Importing is additive. Nothing is deleted, and every inserted record is auditable like a manual registration.
